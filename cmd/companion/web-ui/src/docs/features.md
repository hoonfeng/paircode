# PairCode IDE 功能介绍

PairCode IDE 是一款集成 AI 编程助手的现代化集成开发环境，以「对话即编程」为核心理念，将 AI 代码生成与 IDE 无缝融合。

---

## 核心能力

### AI 对话编程（核心）
- 在右侧对话面板中与 AI 助手自然语言交互
- AI 能理解代码上下文，自动完成文件读写、搜索、执行命令等操作
- 支持多次对话会话管理与切换
- 实时流式显示 AI 推理过程和工具调用

### 自主模式
- 开启后，AI 可自主分析项目结构、扫描 BUG、制定修复计划并自动执行
- 支持多阶段规划-执行闭环（规划 → 执行 → 审查 → 修复）
- 执行过程实时可见，用户可随时中止

### 代码编辑器
- 基于 CodeMirror 6 构建，支持语法高亮、代码折叠、括号匹配
- 支持多标签页编辑
- 支持多种编程语言（Go、TypeScript、Python、Rust、Java 等）
- 十六进制查看器与图片预览

### 文件管理
- 内置文件浏览器，支持目录树展开、文件创建/编辑/删除/重命名
- 支持多工作区文件夹管理
- 快速文件搜索与内容搜索

### Git 集成
- 可视化的 Git 状态查看（已修改、已暂存、未跟踪文件）
- 暂存/取消暂存、提交、推送、拉取
- 分支管理（创建/切换/合并）
- Diff 对比查看
- .gitignore 管理与文件丢弃

### 终端集成
- 内置终端面板，支持多标签页
- 在工作区目录下直接执行命令
- 支持复制粘贴

### 主题系统
- 内置 4 套主题：暗色科技风、白色简约风、暖色温暖风、暗夜紫
- 所有主题统一的字体方案（Inter + JetBrains Mono）

### Skills / MCP 市场
- Skills：可复用的工作流程模板，AI 助手自动按需加载
- MCP（Model Context Protocol）：扩展 AI 能力的服务化工具
- 内置市场浏览与一键安装

### BUG 自动检测与修复
- 自动运行 go vet、go build、go test 检测问题
- 智能分析编译/测试错误，自动生成修复方案
- 支持多次迭代修复

### 多会话并行
- 同时运行多个 AI 对话会话
- 各会话独立维护上下文和状态
- WebSocket 实时推送事件

## 操作界面

| 区域 | 说明 |
|------|------|
| **标题栏** | 顶部菜单栏与工作区名称显示 |
| **活动栏** | 左侧图标栏，切换文件浏览/搜索/Git/设置等 |
| **侧栏** | 文件树、搜索面板、Git 面板等 |
| **主编辑区** | 代码编辑器区域 |
| **对话面板** | 右侧 AI 对话面板 |
| **状态栏** | 底部状态信息显示 |
| **终端面板** | 底部终端区域 |

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| Ctrl+S | 保存当前文件 |
| Ctrl+B | 切换侧栏显示 |
| Ctrl+\` | 切换终端面板 |
| Ctrl+K | 专注模式（隐藏所有面板） |
| Ctrl+Shift+E | 切换到文件浏览器 |
| Ctrl+Shift+F | 全局搜索 |
| Ctrl+Shift+T | 打开对话面板 |
| Ctrl+Shift+C | 切换对话面板 |
