# PairCode IDE 功能介绍

PairCode IDE 是一款集成 AI 编程助手的现代化集成开发环境。你只需用自然语言描述需求，AI 就能理解你的意图，直接生成代码、修改文件、执行命令、管理版本——把 IDE 从工具变为你的编程搭档。

---

## 核心功能

### AI 对话编程

在右侧对话面板中，你可以像跟同事聊天一样与 AI 助手交流。告诉它"创建一个 REST API 接口"或"把这个函数改成异步的"，AI 就能理解你的意图，直接读写文件、搜索代码、执行命令。整个推理过程和工具调用结果实时流式显示，你可以随时看到 AI 在想什么、做了什么。

### 自主编程模式

开启自主模式后，AI 可以独立完成复杂的多步骤开发任务——从分析项目结构、扫描代码问题，到制定修复计划、逐个执行，全程无需你逐条指令。你只需要在关键决策点审核确认，AI 会自动推进到下一个阶段。执行进度实时可见，你也可以随时暂停或中止。

### 智能代码编辑器

内置的代码编辑器支持语法高亮、代码折叠、括号匹配和自动缩进，让代码阅读和编写更加舒适。支持多标签页同时编辑多个文件，并覆盖 Go、TypeScript、Python、Rust、Java 等多种主流编程语言。还内置了十六进制查看器和图片预览功能。

### 文件管理

文件浏览器以目录树的形式展示项目结构，支持展开目录、创建文件、编辑保存、删除、重命名等完整操作。可以同时管理多个工作区文件夹，并在不同项目间快速切换。内置的快速搜索和内容搜索功能，让你在大型项目中也能秒级定位文件。

### Git 集成

Git 操作完全融入对话流程——你可以让 AI 帮你查看文件变更、暂存修改、提交代码、切换分支、推送拉取。所有操作通过自然语言描述即可完成，不需要记忆复杂的 Git 命令。内置的变更对比视图让你清楚看到每次改动的细节。

### 内置终端

终端面板内嵌在 IDE 底部，无需切换窗口即可运行命令。AI 也能直接使用终端——它会自动执行命令并读取结果，然后根据输出决定下一步操作。终端支持多标签页，方便在不同任务之间切换。

### 主题系统

内置多套精心设计的主题，包括暗色科技风、白色简约风、暖色温暖风和暗夜紫风格，适应不同场景和个人偏好。所有主题使用统一的字体方案，保证一致的阅读体验。切换主题即时生效，无需重启。

### Skills / MCP 扩展

Skills 是可复用的工作流程模板，AI 会在开发场景中自动按需加载，让回答更准确高效。MCP（Model Context Protocol）是一种标准化的工具扩展协议，可以给 AI 添加新的能力，比如接入自定义 API、数据库查询或第三方服务。内置市场支持一键浏览和安装。

### 多模型支持

支持接入多种 AI 模型后端，包括 OpenAI、Claude 等主流服务商。你可以为执行任务和制定规划分别配置不同的模型，灵活组合使用。所有模型配置在设置面板中集中管理。

### 对话历史管理

每次对话都会自动保存，你可以在对话列表中查看历史记录、继续之前的对话或开启新话题。对话切换到不同工作区时自动隔离，每个项目都有独立的对话上下文。支持向前翻页加载更早的消息记录。

### 国际化

界面支持多语言显示，可根据偏好选择合适的界面语言。菜单、按钮、提示等界面文本统一管理，确保在不同语言下都有一致的操作体验。

### BUG 检测与修复

AI 能够自动扫描项目中的代码问题——编译错误、测试失败、常见代码缺陷都会被标记出来。AI 会分析错误原因并生成修复方案，你可以审阅后一键应用。对于复杂问题，AI 可以多次迭代修复直到通过所有检查。

## 操作界面速览

| 区域 | 说明 |
|------|------|
| **标题栏** | 顶部菜单栏，显示工作区名称，提供帮助文档入口 |
| **活动栏** | 左侧图标栏，切换文件浏览、搜索、Git 等功能面板 |
| **侧栏** | 文件树、搜索面板、Git 面板等工具区域 |
| **主编辑区** | 代码编辑区域，支持多标签页 |
| **对话面板** | 右侧 AI 对话区域，与 AI 交流的核心界面 |
| **状态栏** | 底部状态信息，显示文件编码、行号列号等 |
| **终端面板** | 底部内置终端，执行命令和脚本 |

## 快捷键一览

| 快捷键 | 功能 |
|--------|------|
| Ctrl+S | 保存当前文件 |
| Ctrl+B | 切换侧栏显示 |
| Ctrl+\` | 切换终端面板 |
| Ctrl+K | 专注模式（隐藏所有面板） |
| Ctrl+Shift+E | 切换到文件浏览器 |
| Ctrl+Shift+F | 全局搜索 |
| Ctrl+Shift+T | 打开对话面板 |
| Ctrl+Shift+C | 切换对话面板 |
