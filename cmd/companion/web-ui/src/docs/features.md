# PairCode IDE 功能介绍

PairCode IDE 是一款纯 Web 端的 AI 辅助编程开发环境。你只需用浏览器打开，在对话面板中用自然语言描述需求，AI 就能理解你的意图，直接生成代码、修改文件、执行命令、管理版本——把 IDE 从工具变为你的编程搭档。

---

## AI 对话编程

**核心交互方式，用自然语言驱动整个开发流程。**

在右侧对话面板中，你可以像跟资深开发者聊天一样与 AI 助手交流。告诉它"创建一个 REST API 接口"或"把这个函数改成异步的"，AI 就能理解你的意图，直接操作文件、搜索代码、执行命令。

- **流式实时输出** — AI 的思考过程和工具调用结果实时显示，你看得到它在想什么、做了什么
- **透明可追溯** — 每一步操作你都可以看到详细上下文，不是黑盒
- **随时打断** — 如果 AI 方向跑偏，可以随时给出反馈，AI 会立即调整

## 自主编程模式

**AI 独立完成复杂的多步骤任务，你只需做最关键的决定。**

开启自主模式后，AI 可以：
1. 分析项目结构，了解代码整体面貌
2. 扫描代码中的编译错误、测试失败和潜在问题
3. 制定修复计划和执行步骤
4. 逐个执行，每步结果实时展示
5. 在关键节点（如写文件、执行危险命令）请求你的审批确认

执行进度实时可见，你可以随时暂停、中止或补充指令，AI 会依据你的反馈调整方案。

## 智能代码编辑器

**内置浏览器端编辑器，支持多语言、多标签页。**

- **语法高亮** — 支持 Go、TypeScript、Python、Rust、Java、C++、HTML、CSS 等主流语言
- **代码折叠** — 折叠函数和代码块，聚焦关键逻辑
- **括号匹配与自动缩进** — 代码结构清晰可见
- **多标签页** — 同时打开编辑多个文件，标签栏快捷切换
- **十六进制查看器** — 查看二进制文件的原始字节内容
- **图片预览** — 在编辑器中直接显示图片文件

## 文件管理

**完整的工作区文件管理能力。**

- **目录树浏览** — 以树形结构展示项目目录，支持展开/折叠
- **文件操作** — 创建、编辑、保存、删除、重命名、移动文件
- **多文件夹支持** — 同时管理多个目录，组合成一个工作区
- **快速切换工作区** — 在最近使用的项目之间一键切换
- **文件搜索** — 按文件名快速定位（Ctrl+P）
- **内容搜索** — 在整个工作区中按关键词搜索代码内容（Ctrl+Shift+F）

## Git 版本控制

**在对话中完成所有 Git 操作，告别记忆复杂命令。**

所有 Git 操作都可通过自然语言完成：

```
"查看当前仓库状态"
"暂存所有修改，提交信息写'修复登录校验'"
"创建一个名为 feature-search 的分支"
"从远程拉取最新代码并合并"
"帮我查看上次提交的改动内容"
```

AI 会自动执行对应的 Git 命令并返回结果。你也可以通过 Git 面板查看文件变更的逐行对比，确认每次改动的细节。

## 内置终端

**浏览器中的终端，无需切换窗口。**

- 终端面板内嵌在 IDE 底部，打开即用
- AI 可以直接使用终端——它会自动执行命令、读取输出并进行分析
- 支持多标签页，方便同时运行不同任务
- 无需安装任何 SSH 客户端，直接在浏览器中操作

## 代码知识图谱（CodeGraph）

**AI 能"看懂"你的代码结构和调用关系。**

CodeGraph 将项目的代码结构构建成可以查询的知识图谱——不只是搜索文本，而是理解函数之间的调用关系、类型的层次结构、文件的依赖网络。AI 可以：

- 准确找到某个函数的所有调用者
- 分析修改某个函数后会影响哪些地方
- 理解结构体/接口的完整继承链
- 查看代码实体的变更历史

## 对话历史管理

**每次对话自动保存，随时回溯。**

- 对话自动持久化到本地磁盘，刷新页面不会丢失
- 左侧对话列表展示所有历史记录，支持继续之前的话题
- 不同工作区的对话自动隔离，各项目互不干扰
- 支持向前翻页加载更多历史消息

## BUG 自动检测与修复

**AI 主动扫描代码问题并生成修复方案。**

- 自动运行编译检查和测试，标记所有错误
- 分析错误根因，生成具体的修复方案
- 支持多轮迭代修复——修复后再次验证，直到全部通过
- 修复前会展示改动内容，你可以审阅确认

## Skills / MCP 扩展

**通过扩展增强 AI 的能力。**

- **Skills（技能）** — 可复用的工作流程模板，AI 在对应场景中自动加载，让回答更准确、更高效
- **MCP（模型上下文协议）** — 标准化的工具扩展协议，可以为 AI 添加自定义能力，比如查询内部数据库、调用第三方 API、访问特定服务
- **内置市场** — 一键浏览和安装社区贡献的扩展

## Lua 自定义工具

**创建属于你自己的 AI 工具。**

如果内置工具不能满足需求，你可以通过 Lua 脚本创建自定义工具：
- 封装常用的命令组合
- 编写自定义的数据处理逻辑
- 实现项目特有的自动化流程
- 创建后 AI 自动识别和使用

## 记忆系统

**AI 能跨会话记住你的偏好和项目决策。**

- AI 会记住你的编码偏好、经常使用的模式和做过的决策
- 下次打开 IDE 时，AI 会自动调用这些记忆，无需重复说明
- 记忆可搜索、可管理，过时的可以手动删除

## 任务与规划管理

**复杂的多步骤开发任务有条不紊地执行。**

- AI 自动分解复杂任务为可追踪的子任务步骤
- 每步的执行状态和结果清晰可见
- 支持依赖关系管理——前置步骤完成后自动触发后续步骤
- 任务清单持久化，重启不会丢失

## 主题与个性化

**按你的喜好定制 IDE 外观。**

- **四套预设主题** — 暗色科技风、白色简约风、暖色温暖风、暗夜紫风格
- **即时切换** — 切换主题立即生效，无需刷新页面或重启
- **统一字体方案** — 界面字体和代码字体分别配置，保证阅读体验

## 多模型支持

**灵活选择 AI 模型后端。**

- 支持 OpenAI、Claude 等主流 AI 服务商
- 可为"执行任务"和"制定规划"分别配置不同的模型
- 所有模型配置在设置面板中集中管理
- 支持自定义 API 地址，可接入私有部署的模型

## 安全设计

**你的代码和数据始终在你的控制之下。**

- **本地运行** — 所有操作在本地计算机执行，不经过第三方云端
- **路径隔离** — 文件操作限定在工作区目录范围内，防止越权访问
- **审批机制** — 写文件和执行命令等敏感操作需用户确认
- **本地地址** — API 服务仅监听 127.0.0.1，默认不对外暴露

## 操作界面速览

| 区域 | 说明 |
|------|------|
| **标题栏** | 顶部菜单栏，显示工作区名称，提供帮助文档和设置入口 |
| **活动栏** | 左侧图标栏，切换文件浏览、搜索、Git 等功能面板 |
| **侧栏** | 文件树、搜索面板、Git 面板等工具区域 |
| **主编辑区** | 代码编辑区域，支持多标签页切换 |
| **对话面板** | 右侧 AI 对话区域，与 AI 交流的核心界面 |
| **状态栏** | 底部状态信息，显示文件编码、行号列号等 |
| **终端面板** | 底部内置终端，执行命令和脚本 |
