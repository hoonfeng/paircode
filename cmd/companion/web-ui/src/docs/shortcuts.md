# 快捷键参考

PairCode IDE 提供了丰富的快捷键，帮助你更高效地编写代码和管理项目。以下按功能分类列出所有可用的快捷键。

---

## 一、通用操作

**控制 IDE 界面面板的显示与隐藏，快速切换工作布局。**

| 快捷键 | 功能 | 适用范围 |
|--------|------|----------|
| Ctrl+B | 切换侧栏（文件浏览器）显示/隐藏 | 全局 |
| Ctrl+\` | 切换终端面板显示/隐藏 | 全局 |
| Ctrl+K | 专注模式：隐藏所有面板，聚焦代码编辑区 | 全局 |
| Ctrl+Shift+C | 切换对话面板显示/隐藏 | 全局 |
| Escape | 关闭当前模态框或菜单 | 全局 |

## 二、文件编辑

**编辑器中常用的编辑操作，与主流编辑器保持一致。**

| 快捷键 | 功能 | 适用范围 |
|--------|------|----------|
| Ctrl+S | 保存当前文件 | 编辑器 |
| Ctrl+Z | 撤销操作 | 编辑器 |
| Ctrl+Shift+Z / Ctrl+Y | 重做操作 | 编辑器 |
| Ctrl+X | 剪切选中的内容 | 编辑器 |
| Ctrl+C | 复制选中的内容 | 编辑器 |
| Ctrl+V | 粘贴剪贴板内容 | 编辑器 |
| Ctrl+A | 全选当前文件内容 | 编辑器 |
| Ctrl+F | 在当前文件中搜索 | 编辑器 |
| Ctrl+H | 在当前文件中查找替换 | 编辑器 |
| Ctrl+P | 按文件名快速打开文件 | 编辑器 |

## 三、导航与视图

**在不同功能面板之间快速切换，无需鼠标操作。**

| 快捷键 | 功能 | 适用范围 |
|--------|------|----------|
| Ctrl+Shift+E | 切换到文件浏览器 | 全局 |
| Ctrl+Shift+F | 全局搜索（在工作区中搜内容） | 全局 |
| Ctrl+Shift+T | 打开对话面板 | 全局 |
| F2 | 重命名选中的文件或文件夹 | 文件树 |
| Ctrl+Tab | 在打开的文件标签页之间切换 | 编辑器 |
| Ctrl+W | 关闭当前文件标签页 | 编辑器 |

## 四、对话面板

**AI 对话输入区的快捷操作。**

| 快捷键 | 功能 | 适用范围 |
|--------|------|----------|
| Enter | 发送消息给 AI | 对话面板 |
| Shift+Enter | 换行（多行输入） | 对话面板 |
| Ctrl+Up | 切换到上一条对话 | 对话面板 |
| Ctrl+Down | 切换到下一条对话 | 对话面板 |

## 五、终端

**终端面板的操作快捷键。**

| 快捷键 | 功能 | 适用范围 |
|--------|------|----------|
| Ctrl+\` | 打开/关闭终端面板 | 全局 |
| Ctrl+Shift+\` | 新建终端标签页 | 终端 |
| Ctrl+W | 关闭当前终端标签页 | 终端 |
| Ctrl+C | 中断当前正在运行的命令 | 终端 |

## 六、多标签页导航

| 快捷键 | 功能 | 适用范围 |
|--------|------|----------|
| Ctrl+Tab | 切换到下一个文件标签页 | 编辑器 |
| Ctrl+Shift+Tab | 切换到上一个文件标签页 | 编辑器 |
| Ctrl+PageUp | 切换到上一个文件标签页 | 编辑器 |
| Ctrl+PageDown | 切换到下一个文件标签页 | 编辑器 |
| Ctrl+W | 关闭当前文件标签页 | 编辑器 |
