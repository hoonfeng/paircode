# 快捷键参考

PairCode IDE 提供了丰富的快捷键，帮助您提高编程效率。

---

## 通用

| 快捷键 | 功能 |
|--------|------|
| Ctrl+B | 切换侧栏显示/隐藏 |
| Ctrl+\` | 切换终端面板 |
| Ctrl+K | 专注模式（隐藏所有面板，全屏编辑） |
| Ctrl+Shift+E | 切换到文件浏览器 |
| Ctrl+Shift+F | 全局搜索 |
| Ctrl+Shift+T | 打开对话面板 |
| Ctrl+Shift+C | 切换对话面板显示/隐藏 |

## 文件编辑

| 快捷键 | 功能 |
|--------|------|
| Ctrl+S | 保存当前文件 |
| Ctrl+Z | 撤销 |
| Ctrl+Shift+Z | 重做 |
| Ctrl+X | 剪切 |
| Ctrl+C | 复制 |
| Ctrl+V | 粘贴 |

## 文件操作

| 快捷键 | 功能 |
|--------|------|
| Ctrl+N | 新建文件 |
| Ctrl+O | 打开文件 |
| Ctrl+P | 命令面板 |

## 终端

| 快捷键 | 功能 |
|--------|------|
| Ctrl+\` | 打开/关闭终端 |
| Ctrl+Shift+\` | 新建终端标签页 |

## 对话面板

| 快捷键 | 功能 |
|--------|------|
| Ctrl+Shift+T | 打开对话面板 |
| Enter | 发送消息 |
| Shift+Enter | 换行（多行输入） |
| Ctrl+Shift+C | 切换对话面板 |

## Git

| 快捷键 | 功能 |
|--------|------|
| Ctrl+Shift+G | 打开 Git 面板 |

## 建议

- 熟练掌握 Ctrl+B 和 Ctrl+K 可以在**全屏编辑**和**浏览模式**之间快速切换
- 善用 Ctrl+\` 随时调出终端执行命令
- 使用 Ctrl+Shift+F 在项目范围内搜索文件内容
