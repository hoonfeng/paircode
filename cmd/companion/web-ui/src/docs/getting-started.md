# 快速开始

欢迎使用 PairCode IDE！以下指南将带你快速上手，从打开项目到用 AI 写代码，只需几分钟。

---

## 安装与启动

PairCode IDE 是桌面应用程序。双击 `companion.exe` 启动，程序会自动在浏览器中打开主界面。如果浏览器没有自动弹出，可以手动访问 `http://localhost:9090` 进入 IDE。

## 打开工作区

启动后，点击左侧活动栏的文件图标或按 `Ctrl+Shift+E` 打开文件浏览器。你可以选择一个项目文件夹作为工作区——所有文件操作和 AI 对话都将在这个工作区范围内进行。

## 开始对话

右侧对话面板是与 AI 交互的核心区域。直接在输入框中用自然语言描述你的需求，例如：

- "创建一个新的 Go 文件，实现一个 HTTP 服务"
- "帮我修改这个函数，增加参数校验"
- "搜索项目中所有调用这个 API 的地方"

AI 会自动理解你的意图，读取文件、生成代码、执行命令，并将过程和结果显示在对话中。按 `Enter` 发送消息，`Shift+Enter` 换行。

## 编辑与保存

AI 生成的代码会直接写入文件，你也可以在编辑器中手动查看和修改。编辑器支持语法高亮、代码折叠和多标签页。按 `Ctrl+S` 保存当前文件的修改。

## 运行与调试

按 `Ctrl+\`` 打开内置终端，在工作区目录下运行命令。你也可以让 AI 帮你执行命令——告诉它"运行项目"或"执行测试"，AI 会自动在终端中执行并返回结果。

## 版本控制

Git 操作完全融入对话。你可以直接对 AI 说"帮我提交代码"或"创建一个新分支"，AI 会自动完成暂存、提交、推送等操作。你也可以通过 Git 面板查看文件变更状态。
