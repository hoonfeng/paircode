PairCode IDE 的 AI Agent 内置了丰富的工具集，用于完成代码阅读、搜索、编辑、 调试、版本控制等任务。以下按功能分类列出所有可用工具的名称和用途。

代码阅读与搜索

工具用途
read_file读取文件内容，支持指定行范围
search_files按通配符查找文件
search_content正则搜索文件内容
find_files_by_patternGlob 模式查找，附带语言/大小信息

CodeGraph（代码知识图谱）

工具用途
codegraph_search按名称搜索代码实体（函数/类型/变量）
codegraph_function按名称查找函数定义位置与签名
codegraph_class获取结构体/接口的完整层次结构
codegraph_callers查询哪些函数调用了指定函数
codegraph_impact分析修改某函数/文件的影响范围
codegraph_file_structure查看文件的实体结构树

文件操作

工具用途
write_file写入/覆盖文件
edit_file精确替换文件中的内容
multi_edit同一文件多处替换
move_file移动/重命名文件
delete_file删除文件

命令执行与网络

工具用途
run_command执行 Shell 命令
run_background后台运行长任务
web_fetch抓取网页内容
web_search搜索引擎查询

网页验证与截图

工具用途
web_debug一站式网页验证（打开+截图+控制台+JS）
screenshot_webpage网页截图
headless_browser无头浏览器渲染获取页面

图像分析（桌面截图 + OCR）

工具用途
image_analyze分析图片颜色/色块/图形
image_ocr图片文字识别
screenshot_desktop截取桌面
screenshot_window按窗口标题截图
screenshot_area按坐标区域截图

Git 与调试

工具用途
git_status/diff/log/show/blame版本控制操作
debug_start/stop/breakpointDAP 调试器控制
debug_continue/next/step_in/out调试执行控制
debug_stack/variables/evaluate调试状态查看

BUG 检测与修复

工具用途
bug_detect全量检测项目 BUG
bug_analyze分析构建/测试输出
bug_fix自动检测并生成修复方案

项目知识库与记忆

工具用途
project_info_*项目知识库读写搜索
memory_*长时记忆读写搜索删除

任务规划与 Skill/MCP

工具用途
update_plan / update_tasks任务规划与进度追踪
skill_* / mcp_*技能与 MCP 管理
marketplace_*市场搜索安装
lua_tool_*Lua 自定义工具管理

AI Agent 会根据任务自动选择合适的工具组合，无需手动指定。用户也可以在对话中显式要求 AI 使用特定工具。
