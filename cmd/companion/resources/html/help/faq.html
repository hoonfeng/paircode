PairCode IDE 是什么？

PairCode IDE 是一个 AI 辅助编程的 Web 版本集成开发环境。它将 AI 对话能力深度融入编码工作流， 你可以像和资深开发者对话一样，通过自然语言描述需求，AI 自动理解上下文并生成代码、修复错误、优化结构。

如何打开一个项目？

点击左侧面板的「打开文件夹」按钮，或通过顶部菜单「文件 → 打开文件夹」选择项目目录。 PairCode 支持同时打开多个文件夹作为工作区。你也可以直接将文件夹拖拽到窗口来打开。

AI 能帮我做什么？

AI 可以帮你生成代码、解释代码逻辑、优化性能、排查错误、编写测试、重构代码、回答技术问题。 只需在聊天面板中用自然语言描述你的需求即可。AI 能理解你当前编辑的文件内容和项目结构。

什么是「自主模式」？

自主模式是 PairCode 的高级特性。开启后，AI 不再只是被动响应，而是主动分析项目状态、 规划任务分配、逐步执行并验证结果。AI 可以自主阅读文件、搜索代码、运行命令、修改代码、构建测试， 适合批量修复错误、实现功能模块等复杂任务。你可以在聊天面板中切换开启/关闭自主模式。

支持哪些编程语言？

编辑器支持 34 种语言的语法高亮，包括 Go、TypeScript/JavaScript、Python、Rust、Java、C/C++、C#、Ruby、PHP、 Swift、Kotlin、Dart、Lua、Bash、SQL、Vue、HTML、CSS、JSON、YAML、Markdown 等。CodeGraph 工具支持 多语言解析（函数查找、调用链分析等）。AI 对话能力不受语言限制。

如何切换 AI 模型？

打开设置面板（可通过命令面板或菜单），在「模型」设置中可以选择不同的 AI 模型提供商和具体模型。 你可以调整模型参数如温度、最大 Token 数等。多模型支持让你灵活选择最适合当前任务的模型。

对话历史保存在哪里？

所有对话自动保存在本地项目中，支持回溯查看历史对话、继续之前的对话。对话采用配对存储机制， 确保用户消息和 AI 回复正确关联。你可以重命名会话、删除不需要的会话。

如何安装 Skills 或 MCP 扩展？

通过「市场」面板（可从菜单或侧栏进入），你可以浏览并安装社区贡献的 Skills（技能）和 MCP 服务器。 安装后，AI Agent 会自动加载并使用这些扩展能力，增强其在特定领域的处理能力。

如何报告问题或提出建议？

你可以通过项目 GitHub Issues 提交反馈，或在社区讨论群中交流。我们非常重视用户的意见和建议， 每个反馈都会认真对待并持续改进 PairCode IDE 的功能和体验。
