PairCode IDE 提供一组 REST API 接口，供前端和外部工具与后端交互。 以下按功能分类列出所有 API 路径及其用途说明。

健康检查

路径说明
GET /health服务健康检查，返回运行状态

文件系统

路径说明
POST /api/read-file读取文件内容
POST /api/write-file写入/覆盖文件
POST /api/list-files列出目录内容
POST /api/search-files按通配符搜索文件
POST /api/search-content按正则搜索文件内容
POST /api/move-file移动/重命名文件
POST /api/delete-file删除文件

工作区管理

路径说明
POST /api/open-folder打开文件夹作为工作区
POST /api/workspace-root获取/设置工作区根目录

系统设置

路径说明
POST /api/settings-get获取设置项值
POST /api/settings-set设置配置项
POST /api/run-command执行 Shell 命令

AI 模型

路径说明
POST /api/chat发送对话消息
POST /api/stop停止 AI 生成
POST /api/models获取可用模型列表

对话管理

路径说明
POST /api/conversations列出历史会话
POST /api/conversation-load加载指定会话
POST /api/conversation-delete删除会话
POST /api/conversation-rename重命名会话

Git 操作

路径说明
POST /api/git-diff查看文件差异
POST /api/git-commit提交变更
POST /api/git-status查看仓库状态
POST /api/git-log查看提交历史

Skills / MCP / 市场

路径说明
POST /api/skills-list列出已安装技能
POST /api/skill-load加载技能详情
POST /api/mcp-list列出 MCP 服务器
POST /api/marketplace-search搜索市场
POST /api/marketplace-install安装市场扩展

其他 API

路径说明
POST /api/token-statsToken 用量统计
POST /api/debug-log调试日志查询
POST /api/memory-*记忆系统读写
WS /api/wsWebSocket 实时通信

注意：所有 API 通过 POST 请求调用，请求和响应均为 JSON 格式。WebSocket 用于流式对话和实时事件推送。
