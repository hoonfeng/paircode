什么是 PairCode IDE？

PairCode IDE 是一个现代化的 AI 辅助编程集成开发环境（Web 版本），它将人工智能对话能力深度融入编码工作流。 不同于传统 IDE，PairCode 以「AI 结对编程」为核心理念——你可以像与资深开发者对话一样，通过自然语言描述需求， AI 自动理解上下文并生成代码、修复错误、优化结构。无需切换工具，在同一个界面内完成编码、调试、版本控制全部环节。

打开工作区

首次使用时，点击左侧面板的「打开文件夹」按钮，或通过顶部菜单「文件 → 打开文件夹」选择一个项目目录。 PairCode 支持同时打开多个文件夹作为工作区根目录。工作区加载后，文件树面板会自动展示目录结构， 你可以在其中浏览、打开、编辑任意文件。

开始对话

右侧聊天面板是 PairCode 的核心交互区。在输入框中用自然语言描述你的需求，例如： 

"创建一个 Rust 命令行工具，读取 CSV 文件并统计每列的平均值"
"帮我解释这段代码的工作原理"
"优化这个函数，让它支持并发安全"
"这个报错是什么意思？怎么修复？"

AI 会根据当前编辑器中的文件内容、项目结构和你提供的上下文，生成精准的回答或代码。 你可以对 AI 生成的代码进行「应用」或「拒绝」操作。

编辑与保存

PairCode 内置了功能完整的代码编辑器，支持语法高亮（34+ 语言）、代码折叠、自动缩进、 行号显示、括号匹配。编辑操作包括：

  • 点击文件树中的文件即可打开编辑器标签页
  • 多标签页管理，支持拖动排序
  • Ctrl+S 保存当前文件，未保存标签会显示圆点提示
  • Ctrl+Z / Ctrl+Y 撤销/重做
  • 右键菜单提供常用编辑操作

运行与调试

集成终端（Ctrl+J 打开）让你无需离开 IDE 即可运行命令。底部面板内置终端， 支持多标签页、复制粘贴、搜索等标准终端功能。对于 Go 项目，你可以直接在终端中执行 go build、 go test 等命令。 PairCode 还内置了 DAP（调试适配器协议）调试器，支持设置断点、单步执行、查看变量值。

版本控制

PairCode 集成了 Git 版本控制面板，在左侧面板可切换至 Git 视图。功能包括：

  • 查看文件变更状态（新增、修改、删除）
  • 暂存/取消暂存文件变更
  • 提交代码并编写提交信息
  • 查看文件差异（Diff）
  • 切换分支、查看提交历史
  • 状态栏显示当前分支名
