AI 对话编程

PairCode 最核心的功能——通过自然语言与 AI 对话来编程。AI 理解你当前编辑的文件内容、 项目结构和历史对话，能生成代码、解释逻辑、重构优化、排查错误。 支持多轮对话，AI 会记住上下文，持续迭代改进代码质量。

自主模式

自主模式是 PairCode 的进阶能力。开启后，AI 不再只是被动响应，而是主动分析项目状态、 规划任务、逐步执行并验证结果。AI 可以自主阅读文件、搜索代码、运行命令、修改代码、 构建测试，形成一个完整的「分析 → 规划 → 执行 → 验证」闭环。 适合批量修复错误、实现功能模块等复杂任务。

智能编辑器

编辑器采用先进的代码编辑组件，支持 34 种语言的语法高亮。内置智能提示、 代码折叠、多光标编辑、自动补全括号、行号显示。标签页管理支持拖拽排序， 右键菜单提供复制路径、在文件管理器中打开等实用操作。

文件管理

树形文件浏览器支持多根工作区、文件/文件夹的创建、重命名、删除操作。 文件搜索支持文件名匹配和内容搜索（正则表达式）。支持拖拽文件到窗口直接打开。 右键菜单提供丰富的文件操作选项。

Git 集成

完整的 Git 版本控制面板：查看文件变更状态、暂存/取消暂存、提交代码、 查看 diff 差异、切换分支、查看提交历史。状态栏实时显示当前分支和变更数量。

内置终端

集成终端模拟器支持多标签页、复制粘贴、搜索、自定义字体大小。 无需切换窗口即可运行构建、测试、Git 等命令。支持右键菜单和常用快捷键。

主题系统

采用 VS Code Dark+ 风格的精美深色主题，所有 UI 元素（标题栏、侧栏、编辑器、 终端、对话面板、状态栏）均统一配色，提供沉浸式编码体验。

Skills / MCP 扩展

PairCode 支持 Skills（技能系统）和 MCP（模型上下文协议）扩展机制。 你可以安装社区贡献的技能来增强 AI 能力，或通过 MCP 服务器接入外部工具和服务。 内置市场面板支持浏览和安装。

多模型支持

支持切换不同的 AI 模型后端，适配多种 LLM 提供商。你可以在设置面板中配置 模型参数（如温度、最大 Token 数），灵活选择最适合当前任务的模型。

对话历史

所有对话自动保存为历史记录，支持回溯、继续之前的对话。对话采用配对存储机制， 确保用户消息和 AI 回复正确关联。

BUG 检测与修复

内置 BUG 自动检测与修复系统：自动运行编译检查和测试，发现错误后由 AI 分析根因 并生成修复方案。支持迭代修正，大幅减少手动排查时间。
