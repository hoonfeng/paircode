PairCode IDE 提供丰富的键盘快捷键，帮助你高效操作。以下列出所有可用快捷键及其功能说明。

通用操作

快捷键功能
Ctrl + N新建文件
Ctrl + O打开文件
Ctrl + S保存当前文件
Ctrl + Shift + S全部保存
Ctrl + Z撤销
Ctrl + Y重做
Ctrl + X剪切
Ctrl + C复制
Ctrl + V粘贴
Ctrl + A全选

导航与视图

快捷键功能
Ctrl + B切换侧栏显示
Ctrl + J切换终端面板
Ctrl + K专注模式（隐藏侧栏/底栏）
Ctrl + P命令面板
Ctrl + Shift + E聚焦文件树

搜索

快捷键功能
Ctrl + F当前文件搜索
Ctrl + H查找替换
Ctrl + Shift + F全局搜索（跨文件）

编辑器

快捷键功能
Ctrl + D选中下一个相同词
Ctrl + /切换行注释
Ctrl + Shift + K删除当前行
Alt + ↑/↓上移/下移当前行
Ctrl + Shift + L选中所有相同词

文件管理

快捷键功能
Ctrl + W关闭当前标签
Ctrl + Tab切换标签页
Ctrl + Shift + O添加文件夹到工作区

提示：你可以在设置面板中自定义部分快捷键绑定。命令面板（Ctrl+P）列出了所有可用的操作和对应的快捷键。
