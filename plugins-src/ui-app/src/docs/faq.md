# 常见问题

## PairCode IDE 是什么？

PairCode IDE 是一款 AI 原生的纯 Web 集成开发环境。与传统 IDE 不同，你只需用浏览器打开，在对话面板中用自然语言描述需求，AI 就能理解你的意图，自动完成代码编写、文件操作、命令执行等工作——让编程从手工操作转变为对话驱动。

## 需要安装桌面客户端吗？

不需要。PairCode IDE 是纯 Web 应用：启动后台服务后用浏览器（推荐 Chrome、Edge、Firefox）访问即可，所有界面在浏览器中渲染。

## 需要先安装 Node.js 吗？

不需要。JS / TS 插件由 IDE 内置的运行时与编译器直接加载（TS 由内置编译器转译），不依赖系统的 Node.js。只有你自己要在项目里跑 Node 工具链时才需要单独安装。

## AI 能做什么？

AI 可以读写和编辑代码文件、在工作区中执行命令、搜索和浏览项目结构、用 Git 管理版本、构建与查询代码知识图谱、处理图片和办公文档、查阅网络资料，还能截图并验证网页效果。日常开发中你能做的事，AI 基本都能帮你完成。

## 如何让 AI 执行命令？

在对话中直接说明需要运行什么命令，例如"运行测试"或"启动项目"，AI 会在终端执行并返回输出。涉及文件写入、命令执行等敏感操作时会先进入审批栏请求你确认。

## 文件保存在哪里？

所有文件都保存在本地工作区目录中。IDE 直接读写本地磁盘上的文件，不经过云端存储；你也能在系统文件管理器里直接找到它们。

## 如何切换 AI 模型？

打开设置面板：

- **设置 → 服务商** — 管理 API 服务商、密钥、模型清单与默认思考档位，可自定义 API 地址接入兼容服务；支持多套预设（如"主力 / 写作备用"）快速切换
- **设置 → AI** — 调整对话与规划使用的模型等全局 AI 行为

对话与制定规划可以使用不同的模型。

## 如何安装更多技能？

在市场中可以浏览和安装三类扩展：**技能**（可复用的工作流程模板）、**MCP**（给 AI 添加新能力的协议扩展）、**插件**（工具集等）。市场支持 npm 与 GitHub 实时搜索，找到后一键安装；也可以在对话中让 AI 帮你安装。

## 工具集、插件、技能有什么区别？

- **技能（Skill）** — 一段可复用的工作流程说明，AI 在相关场景按需加载全文，不改变 AI 能用的工具
- **插件（Plugin）** — 可执行的 JS / TS 代码，能注册工具、面板、设置项、命令；卸载后这些一并消失
- **工具集（Toolset）** — 一份**工具面白名单**：从已装配的工具里挑出一组，固化到 `.pair/toolsets/`

## 如何让 AI 只看到部分工具？

在对话面板切换**工具集**（或在左侧活动栏的「工具集」视图里管理）。切到某个工具集后，AI 的工具面就收敛为该集合内的工具，减少误用、也降低上下文开销。直接说 `/创造 <需求>` 还能让 AI 自动盘点并组合出一个场景工具集。

## 右栏「上下文构成」里的技能、MCP 是什么？

那一栏展示**本次请求的上下文被谁占用**，分六项：系统提示、技能、MCP、历史、工具、其他，均来自后端的真实统计（不是估算显示）：

- **系统提示** — 核心行为准则与项目说明等
- **技能** — 系统提示里「可用技能」清单（技能名 + 描述）占用的部分
- **MCP** — 已装配 MCP 服务器提供的工具定义占用
- **历史 / 工具 / 其他** — 历史消息、内置工具定义、当前输入等

悬停分段条可查看每一项的具体 token 数；卡片末行是上下文窗口的剩余额度。

## 对话历史会丢失吗？

不会。每次对话都会自动保存到本地磁盘，可随时在会话列表中查看历史、继续之前的话题或开启新话题。切换工作区时各项目的对话自动隔离。

## 如何保护隐私？

所有操作都在本地计算机上执行，代码与对话内容不会发送到外部服务器（AI 模型调用除外——你也可以接入本地模型避免数据外出）。文件操作限定在工作区目录范围内，敏感操作需要审批。Web 服务监听所有网络接口（0.0.0.0）：本机用 localhost 访问，局域网设备可用本机 IP 访问；**请勿将端口暴露到公网**。

## 页面刷新后数据还在吗？

大部分会保留，但有一处例外：

- **对话历史** — 自动持久化到磁盘，刷新后完整恢复 ✓
- **设置** — 主题、服务商与模型配置、插件配置等持久化到磁盘 ✓
- **工作区** — 工作区目录与文件夹列表持久化 ✓
- **面板布局** — 侧栏 / 对话面板 / 终端面板显隐、活动栏当前视图、底部面板页签保存在浏览器本地存储 ✓
- **打开的文件标签** — ✗ **不会自动恢复**（刷新后编辑器回到初始状态，文件内容以磁盘为准）

## 编辑器里的代码没有高亮怎么办？

编辑器按扩展名选择语言模式，支持程度分三档：

- **精确语法** — `js/mjs/cjs/jsx`、`ts/tsx`、`py`、`html/htm`、`css/scss/less`、`json`、`md`、`xml/svg`、`sql`
- **借用最接近的解析器** — `go`、`rs`、`java`、`c/cpp/h/hpp`、`rb`、`sh/bash`、`ps1`、`swift`、`kt`（按 JavaScript 模式）；`vue/svelte/php`（按 HTML 模式）；`yaml/yml/toml`（按 Markdown 模式）
- **纯文本** — 其余扩展名

所以高亮「看起来不太对」通常不是故障，而是该扩展名走了近似模式。用常见扩展名保存可获得更准确的高亮。

## 什么是自主模式？和普通对话有什么区别？

**普通模式**：你发一条指令，AI 执行并回复，然后等待下一条指令。

**自主模式**：你交给 AI 一个复杂任务（如"修复所有编译错误"），AI 自动分解任务、逐个执行、迭代验证，直到全部完成；你只在关键节点确认即可。

## 长任务会不会因为预算用尽而停下？

不会。单个执行段有「步数预算」和「工具调用预算」（默认各 120，可在**设置 → Agent** 调整）：任一达到上限，AI 会自动结束这一段并接着开启下一段继续做（对话上下文保留），直到任务完成。你不需要手动催它继续。

## 能让 AI 访问我的私有 API 吗？

可以，通过 MCP（模型上下文协议）扩展实现：

- 在对话中让 AI 添加 MCP 服务器（支持 stdio / SSE / HTTP）
- 或从市场的 MCP 分类中一键安装

接入后其工具会以 `mcp__<服务器>__<工具>` 名称注册给 AI。

## 如何更新到新版本？

打开**设置 → 软件更新**检查并安装新版本。更新后刷新页面即可加载新界面。

## 遇到问题怎么办？

先查阅本文档中心的其他章节（功能介绍、工具文档、API 文档、快捷键）。如果问题仍未解决，直接在对话中向 AI 描述现象，它会尽力协助排查——包括读取日志、复现问题并给出修复方案。
