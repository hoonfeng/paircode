# 快速开始

欢迎使用 PairCode IDE！从这里开始，从打开工作区到用 AI 写代码，几分钟即可上手。

---

## 打开 IDE

PairCode IDE 是纯 Web 应用：启动后台服务后，在浏览器访问对应地址即可使用，无需安装桌面客户端。

> 建议使用 Chrome、Edge 或 Firefox 等现代浏览器。

---

## 设置工作区

工作区是 IDE 操作的基础边界——文件读写、搜索、命令执行都在工作区目录范围内进行。

1. 点击左侧活动栏的**文件浏览器**图标
2. 在面板顶部输入项目文件夹的完整路径
3. 按回车确认，目录树随即展开

活动栏从左到右依次是：**会话**（对话历史与 Token 统计）、**文件浏览器**、**搜索**、**源代码管理**、**工具集**、**插件**、**市场**。

一个工作区可以同时挂载多个文件夹，便于跨目录浏览；在项目之间切换时，对话历史与配置按工作区隔离。

---

## 与 AI 对话

右侧的**对话面板**是核心交互界面：用自然语言描述需求，AI 会自己选工具、改文件、跑验证。

直接输入即可，例如：

- "创建一个 Go 文件，实现一个返回 JSON 的 HTTP 服务"
- "帮我优化这个函数，加上错误处理和参数校验"
- "搜索项目中所有调用了 Post 的地方"
- "运行项目中的所有测试，并告诉我哪些失败了"
- "把我的改动提交到 Git"

按 Enter 发送，Shift+Enter 换行。AI 的思考过程、工具调用与结果会实时流式显示。

### 斜杠命令

在输入框打 `/` 会弹出命令菜单（按前缀过滤，↑↓ 选择，Enter 填入）。命令由后端下发，随已装配的插件增减，当前可用：

| 命令 | 说明 |
|------|------|
| `/agent-teams <目标>` | 启动 AgentTeams 任务编排（`/agent-teams status` 查看状态） |
| `/创造 <需求>` | 创造模式：盘点现有能力并组合出一个场景工具集 |

### 常用对话技巧

| 技巧 | 说明 |
|------|------|
| **明确具体** | 越具体，AI 理解越准确。如"写一个函数"不如"写一个读取 JSON 配置文件的函数" |
| **分步沟通** | 复杂任务可以分步骤告诉 AI：先分析，再重构 |
| **提供上下文** | 粘贴错误信息或代码片段，AI 能给出更精准的修复方案 |
| **直接反馈** | 输出不满意就直接指出问题，AI 会调整方案重新尝试 |
| **拖入文件** | 把文件拖进输入框即作为附件随消息发送 |

## 编辑代码

AI 生成的代码会直接写入文件，你也可以在编辑器中查看和修改：

- **多标签页** — 同时打开多个文件，标签栏切换
- **语法高亮** — 精确支持 JavaScript / TypeScript（含 JSX / TSX）、Python、HTML、CSS / SCSS / LESS、JSON、Markdown、XML / SVG、SQL；Go、Rust、Java、C/C++、Ruby、Shell 等借用最接近的解析器着色
- **代码折叠** — 折叠函数与代码块
- **中文搜索面板** — Ctrl+F 查找、Ctrl+H 替换（支持大小写敏感 / 全词 / 正则）
- **保存** — Ctrl+S 保存当前文件

二进制文件（图片、字体、可执行文件等）可在十六进制查看器中查看，图片文件直接预览。

## 运行与调试

### 使用内置终端

按 Ctrl+\` 打开底部终端面板，它是在工作区目录下运行的完整 PTY 会话。支持多标签页，点标签栏的「+」新建。

### 让 AI 帮你运行

也可以直接说"运行项目并告诉我结果"或"执行 npm test"：AI 会在终端执行命令、读取输出，并据此决定下一步。

---

## 版本控制

Git 操作完全融入对话流程，用自然语言即可完成：

- "查看当前仓库状态"
- "暂存所有修改并提交"
- "创建一个新分支并切换过去"
- "从远程拉取最新代码"

左侧**源代码管理**面板可查看文件变更并逐行对比每次改动。

---

## 右侧栏：当前在发生什么

对话面板右侧是运行状态栏，四张卡片分别是：

| 卡片 | 内容 |
|------|------|
| **运行统计** | 本轮状态、耗时、输出速度、步数、工具调用与 LLM 调用次数 |
| **Token 统计** | 工作区累计输入 / 输出 token、缓存命中率（环形图） |
| **任务进度** | 当前会话的任务清单与完成度，Agent 更新任务后实时刷新 |
| **上下文构成** | 本次请求的上下文被谁占用：系统提示 / 技能 / MCP / 历史 / 工具 / 其他，以及剩余额度 |

## 个性化设置

点击标题栏的**设置**入口打开设置面板，分组如下：

| 分组 | 内容 |
|------|------|
| **AI** | 对话与规划使用的模型等全局 AI 行为 |
| **服务商** | API 服务商、密钥、模型清单、默认思考档位 |
| **Agent** | 段预算（步数 / 工具调用）与自动续跑段数上限 |
| **指令** | 自定义系统指令（AI 的行为准则） |
| **自主模式** | 自主编程模式的开关与参数 |
| **编辑器** | 字号、字体、缩进等编辑体验 |
| **外观** | 主题（8 套，4 暗 4 亮）、强调色、背景图、面板不透明度 |
| **软件更新** | 检查与安装新版本 |
| **团队任务编排** | AgentTeams 相关配置 |
