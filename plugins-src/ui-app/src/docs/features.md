# 功能介绍

PairCode IDE 是一款纯 Web 端的 AI 辅助编程环境：在浏览器中打开，用自然语言描述需求，AI 就能理解意图、生成代码、修改文件、执行命令、管理版本——把 IDE 从工具变为编程搭档。

> 本文按当前实现整理，涉及界面位置与快捷键处均与「快捷键参考」章节一致。

---

## 对话面板

**用自然语言驱动整个开发流程。**

右侧对话面板是核心交互界面。用自然语言描述需求，AI 会自己选择工具、执行并验证：

- **流式实时输出** — 思考过程、工具调用、结果逐步显示
- **透明可追溯** — 每次工具调用都带参数与结果，不是黑盒
- **随时干预** — 可直接反馈或纠正，AI 立即调整方向
- **斜杠命令** — 输入 `/` 弹出命令菜单（`/agent-teams`、`/创造`），随已装配插件增减
- **附件** — 把文件拖进输入框即随消息发送

---

## 自主编程模式

**AI 独立完成多步任务，你只在关键节点做决定。**

开启自主模式后，AI 能自己分析项目、制定计划并逐步执行，你可以随时暂停、中止或补充指令。

**Agent 采用 turn / step 双层循环**：

- **turn / step 双层边界** — 每次工具执行是独立 step（开始 / 结束 / 摘要），每轮交互是 turn，进度颗粒度清晰
- **段预算双闸门 + 自动续跑** — 单个执行段同时受「步数预算」与「工具调用预算」约束，任一达上限即结束本段并自动开启下一段继续干活；续跑段数上限可配。三项都在「设置 → Agent」实时调整
- **会话交接** — 历史过长时自动整理成一份「会话交接·提交消息」（相关性判断 + 目标 / 已完成 / 当前状态 / 关键决策 / 下一步），上下文不再无限膨胀；历史不长时原样注入，不干扰缓存
- **审批与提问** — 敏感操作（写文件、执行命令等）进入审批栏等待确认；AI 需要澄清时通过提问卡片或选项表单征询你的意见
- **监督者驱动** — 自主模式的推进由监督者插件负责，可按目标持续迭代直到验收通过

## 智能代码编辑器

**浏览器内完成全部编辑工作。**

- **语法高亮** — 精确支持 JavaScript / TypeScript（含 JSX / TSX）、Python、HTML、CSS / SCSS / LESS、JSON、Markdown、XML / SVG、SQL；Go、Rust、Java、C/C++、Ruby、Shell、PowerShell、Swift、Kotlin 借用最接近的解析器着色；Vue / Svelte / PHP 按 HTML 模式着色；其余扩展名以纯文本打开
- **中文搜索面板** — Ctrl+F 查找、Ctrl+H 替换，支持大小写敏感 / 全词匹配 / 正则
- **代码折叠、括号匹配、自动缩进**
- **多标签页** — 同时打开多个文件，标签栏切换
- **十六进制查看器** — 查看二进制文件原始字节
- **图片预览** — 直接显示图片文件

---

## 文件管理

- **目录树浏览** — 树形展开 / 折叠
- **文件操作** — 新建、编辑、保存、删除、重命名、移动（节点右键菜单）
- **多文件夹工作区** — 多个目录组合成一个工作区
- **多项目寻址** — 工具与搜索支持 `project` 参数，跨项目精确路由，不越界
- **快速切换工作区** — 在最近使用的项目间一键切换
- **文件名搜索 / 内容搜索** — 内容搜索跨工作区递归，自动跳过依赖、构建产物与运行数据目录
- **自动刷新** — 外部改动会触发目录树刷新（带防抖，保留滚动位置）

## Git 版本控制

**在对话中完成 Git 操作，告别记忆复杂命令。**

- "查看当前仓库状态"
- "暂存所有修改，提交信息为'修复登录校验'"
- "创建一个名为 feature-search 的分支"
- "从远程拉取最新代码"

AI 执行对应操作并返回结果；左侧**源代码管理**面板可查看文件变更与逐行对比。

---

## 内置终端

底部终端面板是在工作区目录下运行的完整 PTY 会话，支持多标签页。AI 也能自主使用终端执行命令、读取输出并据此决定下一步。

---

## 代码知识图谱

CodeGraph 把代码结构建为可查询图谱，让 AI 理解函数调用关系、类型层次与文件依赖：查找某函数的全部调用者、分析改动影响范围、查看完整继承链。

**多项目独立建图** — 多项目工作区中每个项目独立建图，切换不串数据，工具通过 `project` 参数路由。

---

## 对话历史与运行统计

- 对话自动持久化到本地，刷新不丢失；不同工作区对话隔离
- 历史消息按需向前翻页加载
- **长对话自动交接** — 历史过长时生成交接摘要（见「自主编程模式」）
- **断线自动重连** — 连接中断后重连并补齐消息与任务

右栏四张卡片持续反映当前状态：

| 卡片 | 内容 |
|------|------|
| **运行统计** | 本轮状态 / 耗时 / 输出速度 / 步数 / 工具调用 / LLM 调用 |
| **Token 统计** | 工作区累计输入输出与缓存命中率（环形图） |
| **任务进度** | 当前会话任务清单与完成度（Agent 更新后实时刷新） |
| **上下文构成** | 本次请求的上下文占用：系统提示 / 技能 / MCP / 历史 / 工具 / 其他，以及剩余额度 |

## 任务与规划管理

复杂的多步骤任务会被分解为可追踪的子任务，含依赖关系；状态（进行中 / 完成 / 取消）实时同步到右栏「任务进度」卡，清单持久化，重启不丢。

---

## BUG 自动检测与修复

工具集内提供 BUG 检测能力：自动运行编译检查与测试、标记错误位置、分析根因、生成修复方案，修复后再次验证，支持多轮迭代；改动前会展示内容供你审阅。

---

## AgentTeams 任务编排

**把一个大目标拆成有依赖关系的任务图，按序执行并留下证据。**

执行 `/agent-teams <目标>` 后进入编排模式：先规划任务 DAG（需你批准），批准后逐项执行与更新状态；实现 / 验证 / 复审类任务需要契约（目标 + 验收标准），复审未通过会自动开启修复与再复审。适用于需要结构化推进的中大型改造。

## Skills / MCP / 工具集扩展

**通过扩展增强 AI 能力，让 IDE 更贴合你的工作流。**

- **技能（Skills）** — 可复用的工作流程模板，按需加载全文；可启用 / 停用，支持内置、工作区级与全局三个层级
- **MCP（模型上下文协议）** — 标准化工具扩展协议（stdio / SSE / HTTP），可为 AI 添加自定义能力；工具以 `mcp__<服务器>__<工具>` 命名注册
- **工具集（Toolset）** — 按需求组合的工具面白名单，可动态构建、固化到 `.pair/toolsets/`，可导出 / 导入 / 发布
- **场景工具集（创造模式）** — 说 `/创造 需求描述`，AI 先盘点现有能力、再组合出一个场景工具集，之后可在对话面板一键切换，让 AI 只看到当前任务真正需要的工具
- **内置市场** — 三个市场源（技能 / MCP / 插件），支持 npm 与 GitHub 实时搜索、一键安装与卸载；工具集也可在市场分享

## 插件体系

**一切皆插件：工具、面板、设置项、命令、市场源都由插件装配。**

- **JS / TS 插件** — 通过 `cordis(op=define)` 定义，支持 `apply(ctx, config)` 注入服务、定时器与执行锁；TS 由内置编译器直接转译加载，无需 Node.js
- **统一入口** — `cordis` 按 `op` 分派：`define` 定义 / `inspect` 查看与诊断 / `run`·`stop` 装卸 / `services`·`query` 查宿主服务与协议 / `undefine` 撤销
- **沙箱防护** — VM 超时防护、schema 校验，插件异常不影响主进程
- **卸载即消失** — 插件停用 / 删除后，它注册的工具、面板、设置项、命令一并消失

### 创作域插件

除开发工具外，IDE 还装配了一组创作域插件，各自提供面板与配套工具：**美术（art）、设计（design）、建模（model）、音乐（music）、骨骼绑定（rig）、语音（voice）**。

## 项目知识库

**把架构、模块职责与设计决策沉淀为结构化知识，AI 跨会话持续了解你的项目。**

- **树形分支** — 按 目标 / 架构 / 实现 / 关键点 / 设计思想 分类，深挖有细节、浏览有全貌
- **自动加载** — AI 接手项目时先读知识库导航，无需从零分析
- **团队共享** — 存于项目 `.pair/` 目录，随版本控制
- **过期检测** — 校验条目引用的文件 / 目录是否仍存在
- **协作文件分层** — 项目说明、环境配置、开发指南分层管理

## 安全设计

- **本地运行** — 所有操作在本机执行，不经过第三方云端
- **路径隔离** — 文件操作限定在工作区目录范围内
- **审批与范围控制** — 敏感操作进入审批栏确认；可配置审批的放行 / 拦截范围
- **工具面收敛** — 通过工具集限定 AI 可见的工具，减少误用
- **监听地址** — 服务监听所有网络接口（0.0.0.0），本机用 localhost 访问，局域网设备用本机 IP；请勿将端口暴露到公网
