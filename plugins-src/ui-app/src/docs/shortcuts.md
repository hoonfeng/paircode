# 快捷键参考

PairCode IDE 的快捷键以「不劫持浏览器保留键」为界——Ctrl+T、Ctrl+W、Ctrl+N 等留给浏览器，所有面板操作都同时提供鼠标入口，快捷键只是加速方式。

> 下表以当前实现为准（逐项对照源码键位处理核对，非设计约定）。

---

## 一、全局快捷键

**在任意界面生效。输入框（`<input>` / `<textarea>`）聚焦时不触发，避免影响打字。**

| 快捷键 | 功能 |
|--------|------|
| Ctrl+B | 切换左侧栏显示 / 隐藏 |
| Ctrl+\` | 切换底部终端面板显示 / 隐藏 |
| Ctrl+K | 专注模式：收起侧栏与会话列表、聚焦编辑区（再按还原原状态） |
| Ctrl+Shift+C | 切换右侧对话面板显示 / 隐藏 |
| Ctrl+Shift+T | 打开右侧对话面板 |
| Ctrl+Shift+L | 切换「会话列表 + Token 统计」栏显示 / 隐藏 |
| Ctrl+Shift+E | 切到文件浏览器（会先退出专注模式） |
| Ctrl+Shift+F | 切到全局搜索（会先退出专注模式） |
| Escape | 关闭当前弹窗 / 菜单 / 浮动面板 |

---

## 二、代码编辑器

编辑器为 CodeMirror 6：下列自定义键位之外，同时保留其标准键位。

| 快捷键 | 功能 |
|--------|------|
| Ctrl+S | 保存当前文件（仅在有未保存改动时写盘） |
| Ctrl+Z | 撤销 |
| Ctrl+Shift+Z 或 Ctrl+Y | 重做 |
| Ctrl+F | 打开**中文搜索面板**（编辑器内有选中文本时自动填入） |
| Ctrl+H | 打开搜索面板并定位到替换输入框 |
| Escape | 关闭搜索面板 |

搜索面板支持：大小写敏感、全词匹配、正则表达式、逐个替换 / 全部替换。

CodeMirror 标准键位（选摘，随语言包而定）：`Ctrl+D` 选中下一个相同内容（多光标）、`Ctrl+/` 切换行注释、`Ctrl+Space` 触发补全、`Ctrl+Shift+[` / `Ctrl+Shift+]` 折叠 / 展开代码块、`Tab` 缩进（多行选中时整块缩进）。

---

## 三、对话面板

| 快捷键 | 功能 |
|--------|------|
| Enter | 发送消息；若 `/` 命令菜单正展开，则先把高亮命令填入输入框（再按才发送） |
| Shift+Enter | 输入换行 |
| `/` | 打开命令菜单（继续打字即按前缀过滤） |
| ↑ / ↓ | 在命令菜单中上下移动高亮项 |
| Escape | 关闭命令菜单 |

**可用命令**（由后端 `/api/commands` 下发，随已装配插件增减）：

| 命令 | 说明 |
|------|------|
| `/agent-teams <目标>` | 启动 AgentTeams 任务编排（`/agent-teams status` 查看状态） |
| `/创造 <需求>` | 创造模式：盘点现有能力并组合出一个场景工具集 |

对话输入框还支持：

- 拖拽 / 粘贴文件 —— 作为附件加入本条消息
- 输入框可拖动上边缘调整高度
- 输出中断开连接会自动重连并补齐该会话的消息

---

## 四、文件树与终端

这两处以鼠标操作为主，没有额外的全局键盘绑定：

| 操作 | 方式 |
|------|------|
| 重命名 / 新建 / 删除 / 复制路径 | 文件树节点**右键菜单**（菜单里标注的 F2 等为习惯性提示） |
| 新建终端标签 | 终端面板标签栏的「+」按钮 |
| 关闭终端标签 | 标签上的关闭按钮 |
| 中断正在运行的命令 | 终端内的 Ctrl+C（由终端程序本身处理） |

> 终端是一个完整的 PTY 会话：Ctrl+C、Ctrl+D、↑ 历史等按键都由终端程序处理，IDE 不拦截。关掉终端标签即结束该会话的进程。
